How friends join (three steps)
  1. Both devices open the exact same V3Y game. Configure the same Supabase project under One-time setup (only needed once per browser).
  2. Player 1 presses CREATE ROOM and shares the three-digit code when it says READY.
  3. Player 2 enters the code and presses JOIN ROOM. When both names appear, select colors/map, then each press START RIDING.

Supabase is an actual hosted connection service. It avoids peer-to-peer connection negotiation, but you still need internet and a free Supabase project. Server-connected does not mean your friend has joined yet.
