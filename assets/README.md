# Embedded audio

The current game HTML is self-contained for reaction audio and music. Run `npm run extract:audio` to recover WAV voice clips, MP3 music loops, and reaction metadata for editing. This command does not change the game. When editing a clip, update its embedded data, metadata duration and matching bubble together; verify natural-speed playback and interruption protection.

Raw uploaded videos and the owner's browser tuning exports are not included. Ask for the original recording if a new edit needs audio beyond the embedded excerpt.
